# finite-state-engine

A finite state engine demo application

**Please note**: This application requires yarn v1.22.x and node v20.x as prerequisites

## Initial application local setup
* Pull this repo
* Run `yarn install` to install package dependencies
* *(OPTIONAL)* Run `husky install` to install husky hooks

## Running unit tests
* Run `yarn test`

## Running the stand-alone application
* Run `yarn dev`
* Proceed to `https://localhost:3000/` with a web browser to see the application running in dev mode

## Building the application for production
* Run `yarn build`
* The built application can be previewed by running: `yarn preview`
* Proceed to `https://localhost:3000/` with a web browser to see the application running in built mode
